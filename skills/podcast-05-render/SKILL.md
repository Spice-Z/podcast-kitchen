# Step 5: render and loudness
Before render, `gate.py` mutes each speaker track outside its own speech regions (VAD ∪ aligned transcript ∪ laughs ∪ backchannels; pad 150/250 ms, merge < 300 ms, 15 ms fades, `gate.attenuation_db`), gates short unvoiced/noise-like no-text VAD islands (sniff, cough, throat-clear) unless laughter, and fills room tone on `gate.fill_track` where every track is gated; render reads `work/gate/` and takes room tone from the ungated levelled tracks. `render.py` applies only approved edits (snap ±`render.snap_window_ms`, `render.crossfade_ms` equal-power on all tracks, room tone, `render.duck_db`), writes `work/mix.wav` (dual-mono) and `work/timemap.json`. `loudness.py`: ffmpeg loudnorm two-pass linear to `loudness.target_lufs` / `loudness.max_true_peak_dbtp`, fails if not linear; writes only the 192k stereo MP3 (temp WAVs deleted after encoding; no WAV master). Structural edits `opening_chatter` (cut small talk before the first theme line of the Zencastr transcript) and `edge_trim` (head/tail silence to `structure.edge_silence_s`) are added by `label_store.py build` from config `structure`; report the opening cut point with the transcript lines before/after it.
