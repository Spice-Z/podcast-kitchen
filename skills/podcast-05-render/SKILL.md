# Step 5: render and loudness
Before render, `gate.py` mutes each speaker track outside its own speech regions (VAD ∪ laughs ∪ backchannels, with transcript words counted only where they overlap own VAD islands — alignment smear beyond VAD is dropped; pad 150/250 ms anchored to VAD speech edges, merge < 300 ms, 15 ms fades, `gate.attenuation_db`), gates short unvoiced/noise-like VAD islands without firm text (a word mostly inside the island) unless laughter/backchannel, mutes unvoiced bursts inside regions but outside voiced VAD (pad zones, merged gaps; sub-window classify) and unvoiced runs ≥ `gate.edge_tail_min_s` glued to a voiced island's head/tail (keeping `gate.edge_keep_s` next to speech), and fills room tone on `gate.fill_track` where every track is gated (room tone window = quietest VAD-free and burst-free window; source in logs/gate.json `roomtone_source`); render reads `work/gate/` and takes room tone from the ungated levelled tracks. `render.py` applies only approved edits (snap ±`render.snap_window_ms`, `render.crossfade_ms` equal-power on all tracks, room tone, `render.duck_db`), writes `work/mix.wav` (dual-mono) and `work/timemap.json`. `loudness.py`: ffmpeg loudnorm two-pass linear to `loudness.target_lufs` / `loudness.max_true_peak_dbtp`, fails if not linear; writes only the 192k stereo MP3 (temp WAVs deleted after encoding; no WAV master). Structural edits `opening_chatter` (cut small talk before the first theme line of the Zencastr transcript) and `edge_trim` (head/tail silence to `structure.edge_silence_s`) are added by `label_store.py build` from config `structure`; report the opening cut point with the transcript lines before/after it.
